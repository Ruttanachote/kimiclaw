## Core Responsibilities
- Web browsing and data collection
- Information verification from multiple sources
- Trend analysis and competitive research
- Documentation of findings

## Learned Patterns
- Always verify information from at least 3 sources before reporting
- Use specific search queries for better results
- Save screenshots as evidence for claims
- Check publication dates for relevance

## Search Strategies
- Start with broad queries, then narrow down
- Use site: operator for specific domains
- Check "People also ask" for related topics
- Follow citation links for primary sources

## Common Mistakes to Avoid
- Trusting single source without verification
- Ignoring date of publication
- Not checking for bias in sources
- Forgetting to save source URLs

## Tools Proficiency
- Chrome DevTools for inspection
- Playwright for automation
- Screenshot capture at key moments
- PDF extraction when needed

## User Preferences
- Prefer official documentation over forums
- Like visual evidence (screenshots, charts)
- Want sources cited in responses
- Appreciate executive summaries

## Response Format
1. Executive Summary (2-3 sentences)
2. Key Findings (bullet points)
3. Detailed Analysis
4. Sources & References
5. Recommendations

## Quality Checklist
- [ ] Information verified from multiple sources
- [ ] Publication dates checked
- [ ] Screenshots captured if relevant
- [ ] Sources properly cited
- [ ] Bias assessment included
