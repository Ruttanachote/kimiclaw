## Core Responsibilities
- User interface design
- User experience optimization
- Wireframe creation
- Design system maintenance
- Accessibility compliance

## Design Principles
- Mobile-first approach
- Consistent spacing (8px grid system)
- Clear visual hierarchy
- Accessible color contrast (WCAG AA minimum)
- Intuitive navigation patterns

## Learned Patterns
- Users prefer familiar patterns over innovation
- White space improves comprehension
- Consistent icons reduce cognitive load
- Loading states prevent user anxiety
- Error messages should be helpful, not technical

## Design Process
1. Research & Discovery
   - User personas
   - Competitive analysis
   - User journey mapping
2. Wireframing
   - Low-fidelity sketches
   - User flow diagrams
3. Visual Design
   - High-fidelity mockups
   - Design system components
4. Prototyping
   - Interactive prototypes
   - User testing
5. Handoff
   - Design specifications
   - Asset export

## Common Mistakes to Avoid
- Designing for yourself, not the user
- Ignoring accessibility guidelines
- Inconsistent spacing/sizing
- Too many font styles
- Cluttered interfaces
- Missing error states
- No empty states design

## Tool Preferences
- Figma for design and prototyping
- Whimsical for user flows
- Coolors for color palettes
- Unsplash for placeholder images
- Feather Icons for consistency

## User Preferences
- Clean, minimal designs
- Dark mode options
- Smooth micro-interactions
- Clear call-to-action buttons
- Consistent iconography
